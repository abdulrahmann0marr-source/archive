هتتنشر مباشرة على الموقع الحي — الصفحة دي خاصة بيك بس

مفتاح الدخول (مرة واحدة فقط)
هيتحفظ في المتصفح بتاعك بس، ومش بيتبعت لحد غير GitHub مباشرة.
إزاي أجيب الـ Token ده؟ (خطوة تعملها مرة واحدة بس)
  1. روح لـ github.com/settings/tokens?type=beta
  2. دوس Generate new token
  3. في Repository access اختار Only select repositories وحدد الريبو archive
  4. تحت Permissions → Repository permissions، دور على Contents وخليها Read and write
  5. دوس Generate token واحفظ القيمة اللي هتظهر (تبدأ بـ github_pat_...) — مش هتقدر تشوفها تاني بعد كده
  6. الصقها في الخانة اللي فوق
اختر مقالة
هيتحمّل من الأرشيف تلقائيًا بمجرد ما تحط التوكن.
بيانات المقالة
رابط مباشر لصورة. شوف "إزاي أضيف صور؟" تحت لشرح المصادر المجانية.
كل فقرة في سطر منفصل، وسايب سطر فاضي بينها وبين اللي بعدها.
عشان تحط صورة *جوه* النص (مش غلاف)، اكتب سطرها لوحده كده: IMG:https://رابط-الصورة.jpg
إزاي أضيف صور؟ (مجانًا)
الطريقة الأسهل: ارفع الصورة على imgur.com/upload (مجانًا، من غير حساب)، بعد الرفع دوس بزر الماوس اليمين على الصورة → Copy image address، والصق الرابط في خانة "صورة الغلاف" أو جوه IMG: في النص.

أو: ارفع الصورة كملف داخل الريبو بتاعك على GitHub (Add file → Upload files) جوه فولدر اسمه images، وبعدين استخدم المسار زي كده: images/اسم-الصورة.jpg
