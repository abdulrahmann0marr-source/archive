# أرشيف عبدالرحمن — دليل الاستخدام

الموقع دلوقتي 3 ملفات:
- `index.html` — الأرشيف نفسه اللي بتشاركه مع الناس
- `articles.json` — بيانات كل المقالات
- `admin.html` — صفحة الإضافة الخاصة بيك، بتنشر مباشرة على GitHub

الطريقة القديمة (تعديل الكود يدويًا) ولّت. دلوقتي تفتح `admin.html`، تحط الـ Token
بتاعك مرة واحدة، وبعد كده تضيف أي مقالة من فورم عادي زي أي موقع.

## النشر (مجانًا) عبر GitHub Pages

1. اعمل حساب على github.com لو معندكش.
2. اعمل Repository جديد، اسمه مثلاً `archive`، خليه Public.
3. ارفع ملف `index.html` (Add file → Upload files).
4. من Settings → Pages، اختار Branch: `main`، فولدر: `/root`، واحفظ.
5. بعد دقيقة أو اتنين، الموقع هيبقى شغال على رابط زي:
   `https://username.github.io/archive/`

هتحتاج تكرر الخطوة 3 (رفع الملف من جديد) كل مرة تضيف أو تعدّل مقالة.

## إزاي تضيف مقالة جديدة (الجزء اللي "بس أنت" تقدر تعمله)

بما إن الموقع Static (يعني مفيش تسجيل دخول ولا لوحة تحكم)، إضافة المقالات بتتم
بإنك تفتح ملف `index.html` بأي محرر نصوص (حتى Notepad أو VS Code)، وتدور على الجزء
اللي مكتوب فوقه تعليق:

```
ARTICLES — هذا هو المكان الوحيد اللي تحتاج تعدّله لإضافة مقالة جديدة
```

هتلاقي مصفوفة (Array) فيها كل المقالات. كل مقالة عبارة عن كائن زي ده:

```js
{
  slug: "esm-mokhtasar-belingelizy",   // معرف فريد، بالإنجليزية، من غير مسافات
  title: "عنوان المقالة",
  subtitle: "عنوان فرعي (اختياري، احذف السطر لو مش عايزه)",
  category: "مقالة",                   // مقالة / تقرير / مراجعة / مقابلة
  date: "2024",
  ready: true,                          // true = تظهر كاملة، false = تظهر كمسودة بس
  content: [
    "الفقرة الأولى...",
    "الفقرة الثانية...",
    "الفقرة الثالثة..."
  ]
}
```

انسخ الكائن ده، الصقه في أول المصفوفة (أو في أي مكان فيها)، وغيّر بياناته. كل فقرة
في `content` لازم تكون بين علامتي اقتباس " " وبعدها فاصلة `,` — ولو في علامة اقتباس
جوه النص نفسه، حطلها `\` قبلها كده: `\"`.

في 7 مقالات مسجلة بالفعل بعناوينها بس من غير نص (`ready:false`) — دي المقالات اللي
ذكرتها من قبل. تقدر تدور عليها في نفس المصفوفة وتحط نصها الكامل في `content`، وتغيّر
`ready` من `false` لـ `true` عشان تظهر كاملة في الأرشيف.

## ليه الطريقة دي؟

بما إن الموقع مجاني ومفيش سيرفر بيشغّله، مفيش طريقة "تدخل تضيف مقالة" من المتصفح
مباشرة زي ووردبريس مثلاً — لازم تعديل الملف ورفعه من جديد. الميزة إن ده بيخليه
خاص تمامًا: محدش غيرك عنده صلاحية يعدّل أو يضيف حاجة، لأن التعديل بيتم من حساب
GitHub بتاعك إنت بس.

لو حبيت مستقبلاً تتحول لموقع فيه لوحة تحكم حقيقية (تضيف مقالة من على الموبايل من
غير ما تفتح كود)، ده هيحتاج سيرفر واستضافة مدفوعة غالبًا — قولّي لو وصلت للمرحلة دي.

## إضافة مقالة (الطريقة الجديدة، من غير كود)

1. افتح `admin.html` على موقعك، مثلاً:
   `https://abdulrahmann0marr-source.github.io/archive/admin.html`
2. **أول مرة بس**: هتحتاج تجيب GitHub Token — الخطوات مكتوبة داخل الصفحة نفسها
   تحت "إزاي أجيب الـ Token ده؟". لخّصها:
   - github.com/settings/tokens?type=beta → Generate new token
   - Repository access: Only select repositories → archive
   - Permissions → Contents → Read and write
   - Generate token، وانسخ القيمة (تبدأ بـ github_pat_...)
3. الصق الـ Token في الخانة، واملأ عنوان المقالة، القسم، والنص الكامل
   (سيب سطر فاضي بين كل فقرة والتانية).
4. دوس **انشر المقالة**. هيتحدث الموقع تلقائيًا خلال دقيقة أو اتنين.

الـ Token بيتحفظ في متصفحك بس (مش بيتبعت لأي حد غير GitHub مباشرة)، فمش
هتحتاج تكتبه تاني في المرات الجاية على نفس الجهاز.

⚠️ الـ Token ده بيدي صلاحية الكتابة على الريبو — متشاركوش مع حد، ومتحطوش
في أي مكان تاني غير خانة الإدخال دي.

## رفع التحديث الحالي

عندك 3 ملفات محدّثة: `index.html`، `articles.json`، `admin.html`.
ارفعهم الثلاثة مع بعض (Add file → Upload files) في نفس المستوى (مش جوه فولدر)،
و Commit. بعد كده admin.html هيبقى شغال.

## تعديل مقالة موجودة أو حذفها

في `admin.html` دلوقتي هتلاقي قائمة منسدلة فوق ("اختر مقالة") بتتحمل تلقائيًا
بمجرد ما تحط التوكن. اختار أي مقالة منها:

- كل بياناتها هتظهر في الفورم تحت جاهزة للتعديل.
- الزرار هيتغير لـ "احفظ التعديلات" بدل "انشر المقالة".
- هيظهر زرار أحمر "احذف المقالة دي" لو حبيت تشيلها نهائيًا.

لو سبت القائمة على "— مقالة جديدة —"، هيشتغل زي الأول: ينشر مقالة جديدة.

## إضافة صور

فيه خانتين للصور في الفورم:

1. **صورة الغلاف** — صورة واحدة بتظهر فوق المقالة، تحت العنوان مباشرة.
2. **صور جوه النص** — في مكان النص، اكتب سطر لوحده بالشكل ده:
   `IMG:https://رابط-الصورة.jpg`
   وهتتحول تلقائيًا لصورة في مكانها بالظبط لما تُنشر.

### مصادر الصور المجانية

- **الأسهل**: ارفع الصورة على [imgur.com/upload](https://imgur.com/upload) من غير
  حساب، وانسخ رابطها المباشر (بزر يمين على الصورة → Copy image address).
- **أو**: ارفع الصورة كملف داخل الريبو بتاعك (فولدر اسمه `images` مثلاً)، واستخدم
  المسار زي `images/اسم-الصورة.jpg`.
